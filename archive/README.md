# Legacy research archive

This directory preserves old experiments that preceded `src` package implementation

- `notebooks/` contains standalone exploratory notebooks from the original
  project root.
- `legacy-experiments/` keeps notebooks, scripts, logs, checkpoints, and
  supporting files whose original directory structure is useful context.
- `legacy-results/` contains figures generated by those experiments.

These files are historical references. Current training, evaluation, model
caches, and tracked experiment artifacts are produced through `scripts/`,
`experiments/`, `model_cache/`, and `results/`.
